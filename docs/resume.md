# 简历与面试展示

**项目名称：搭把手｜校园跑腿互助平台（Vibe Coding 作品）**  
[GitHub 作品集](https://github.com/setout472/campus-errand-portfolio) · [在线体验](https://campus-dabashou-20261015.mapletulip512.chatgpt.site/)

### 简历可用表述

基于校园取件、代买等顺路需求，使用 AI 编程工具搭建并部署免登录交互原型；设计发布、接单、送达、确认、评价流程，将履约信用与具体任务关联。通过桌面与手机布局、9 项业务回归测试及同域名迭代，验证核心体验。

### 面试演示顺序

1. **展示需求判断**：搜索目的地，再按校区筛选；解释为什么先显示路线与时限。
2. **展示关键决策**：接单、送达，然后停在“待确认”。说明接单人不应自行确认自己的履约结果。
3. **展示验证**：模拟发布者确认并评价，打开信用明细，对照测试里的重复确认用例。
4. **说明边界**：当前数据保存在浏览器。多人版本首先要解决身份校验与抢单并发，而不是扩大功能清单。
